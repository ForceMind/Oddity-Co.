# 项目提示词（Oddity Co）

本文件用于后续让 AI 快速进入项目上下文，避免破坏当前多文件架构。

## 全局上下文提示词

你正在维护一个纯前端游戏项目“奇物公司（Oddity Co）”。

核心玩法：
1. 材料组合创建奇物
2. 奇物通过照料从 1 阶段成长到 5 阶段
3. 图鉴收集 + 配方情报解锁 + 公司订单
4. 存在突变/异常状态事件，会影响成长效率
5. Canvas 绘制可视化宠物形态

必须遵守：
- 不要把逻辑重新塞回单个 HTML。
- 优先在 `src/data` 增量改数据，在 `src/game` 改玩法逻辑，在 `src/render` 改表现。
- 保持移动端与桌面端可用。
- 不破坏现有存档字段兼容（`oddity_company_v2`）。
- 订单相关逻辑集中在 `src/data/orders.js` 和 `src/game/orders.js`。
- 状态事件定义集中在 `src/data/effects.js`，结算在 `src/game/simulation.js`。

## 提示词模板

### 1) 新增配方与物种

请为“奇物公司”新增 3 条配方和至少 8 个新物种，并满足：
- 在 `src/data/recipes.js` 扩展
- 每条配方包含普通/罕见/怪异概率分布
- 至少 1 个隐藏产物
- 给每个物种补齐 shape、palette、eyeBase、hornOptions、tailOptions、patternOptions
- 不修改已有函数签名
- 最后给出改动文件和平衡性说明

### 2) 调整成长平衡

请调整成长系统，让前 2 阶段更快，后 2 阶段更需要精细照料：
- 修改 `src/game/simulation.js` 的衰减和成长公式
- 给出调整前后预期体验差异
- 保留 5 阶段结构和现有照料动作
- 不新增全局依赖

### 3) 增加新照料动作

请在不破坏现有 UI 架构前提下新增 2 个照料动作：
- 在 `src/game/simulation.js` 的 `CARE_ACTIONS` 扩展动作定义
- 在 `src/render/dom.js` 确保动作按钮自动渲染
- 动作需要有明显收益与代价，避免纯正收益
- 更新 README 的玩法说明

### 4) 可视化增强

请增强宠物可视化表现：
- 仅修改 `src/render/petPainter.js` 和必要样式
- 为第 4、5 阶段增加更明显的动态特效
- 保持性能稳定，避免创建大量对象导致卡顿
- 给出你使用的绘制策略说明

### 5) 修复问题

你将收到一个 bug 描述，请：
- 先定位到具体模块（data/game/render）
- 只改必要文件
- 提供复现条件、根因、修复点
- 不要引入与 bug 无关的重构

### 6) 扩展订单系统

请为“奇物公司”扩展公司订单系统，并满足：
- 仅在 `src/data/orders.js` 与 `src/game/orders.js` 新增/调整规则
- 每条订单都要有明确进度计算方式
- 奖励需包含研究点，可选材料奖励
- 避免生成“创建即完成”的订单
- 最后输出新增订单列表和触发条件

### 7) 扩展异常状态

请扩展突变/异常状态系统，并满足：
- 在 `src/data/effects.js` 定义状态，在 `src/game/simulation.js` 接入结算
- 每个状态必须说明触发条件、持续刻数、收益/惩罚
- 负向状态可被至少一种照料动作抑制
- 不要在 UI 层写业务规则

## 输出格式建议

每次改动后输出：
1. 改动摘要
2. 修改文件列表
3. 风险点与回归建议
4. 如涉及数值平衡，附上参数对比
