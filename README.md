# 奇物公司（Oddity Co）

一个以“研发奇怪生物并养大”为核心的网页游戏 Demo。当前版本提供了完整闭环：

1. 组合材料创建奇物
2. 在育成仓中选择当前培养对象
3. 通过照料动作维持状态并推进成长
4. 从第 1 阶段成长到第 5 阶段（奇变体）
5. 通过图鉴与配方情报系统持续收集

## 当前玩法

### 研发（创建奇物）
- 材料：气球、胶带、灰尘、阳光、湿气、静电
- 研发台：3 个槽位，放入 2-3 个材料后可创建奇物
- 已有配方与隐藏稀有产物；未知组合会进入失败池
- 创建会产出研究点，可用于购买配方情报

### 养成（5 阶段）
- 阶段：胚团 -> 幼体 -> 少成体 -> 成体 -> 奇变体
- 属性：饱腹、心情、清洁、体力
- 照料动作：喂食、互动、清洁、休息、稳定激发
- 时间推进：每 5 秒一个成长刻，属性会自动衰减
- 属性越健康，成长值增长越快；状态过低会显著拖慢成长

### 收集系统
- 育成仓：可同时保存多个奇物，并切换当前培育体
- 图鉴：记录首次发现物种
- 配方情报：消耗研究点逐条解锁提示

## 可视化系统

`src/render/petPainter.js` 使用 Canvas 绘制宠物形态，依据以下维度动态生成：
- 物种基因：体型（orb/blob/spiky/cube/jelly）、眼睛数量、角、尾巴、纹理
- 成长阶段：体型、纹理密度、特效（第 5 阶段有光环）
- 状态反馈：表情会受心情影响

## 项目结构

```text
index.html
src/
  main.js                  # 入口，事件绑定、时间循环、持久化提交
  styles/main.css          # 全局样式与响应式布局
  core/
    utils.js               # 通用工具（权重抽取、限幅、格式化）
    storage.js             # localStorage JSON 封装
  data/
    materials.js           # 材料定义
    recipes.js             # 配方、物种库、稀有度奖励
    stages.js              # 5 阶段成长配置
  game/
    state.js               # 存档模型、迁移、日志
    crafting.js            # 材料槽位、创建逻辑、补给、情报解锁
    petFactory.js          # 根据物种模板生成宠物实例
    simulation.js          # 时间推进、衰减、成长、照料动作
  render/
    dom.js                 # UI 渲染与 DOM 交互
    petPainter.js          # Canvas 可视化绘制
docs/
  PROJECT_PROMPT.md        # AI 协作的项目提示词
```

## 本地运行

直接打开 `index.html` 即可运行（纯前端，无构建步骤）。

## 数据存档

- 使用 `localStorage`
- 存档 key：`oddity_company_v2`
- 支持基础迁移（旧字段兼容与默认值回填）

## 扩展建议

1. 在 `src/data/recipes.js` 新增物种与配方，不需改核心逻辑。
2. 在 `src/game/simulation.js` 调整衰减/成长参数进行平衡性迭代。
3. 在 `src/render/petPainter.js` 增加新体型绘制函数，扩展视觉风格。
4. 可进一步加入任务系统、经济系统、突变事件和音效系统。
