# 奇物公司（Oddity Co）

一个以“研发奇怪生物并养大”为核心的网页游戏 Demo。当前版本提供完整闭环：

1. 组合材料创建奇物
2. 照料奇物并推进 5 阶段成长
3. 图鉴收集 + 配方情报 + 公司订单
4. 重复怪物自动共鸣吸收，避免仓库无限堆叠
5. 音效反馈 + BGM + Canvas 动态动画
6. 移动端三段流程（实验/培育/公司）单屏切换玩法（无需页面滚动）

## 当前玩法

### 研发（创建奇物）
- 材料：气球、胶带、灰尘、阳光、湿气、静电
- 研发台：3 个槽位，放入 2-3 个材料后可创建奇物
- 已有配方与隐藏稀有产物；未知组合会进入失败池
- 创建会产出研究点，可用于购买配方情报和商店道具

### 相同怪物处理（已实现）
- 首次获得某物种：进入育成仓，作为可培养个体
- 再次获得同物种：不再新增同质个体，自动转为“共鸣样本”
- 共鸣样本会强化已存在同物种（加成长和属性）并增加样本计数
- 图鉴会显示该物种累计发现次数

### 养成（5 阶段）
- 阶段：胚团 -> 幼体 -> 少成体 -> 成体 -> 奇变体
- 属性：饱腹、心情、清洁、体力
- 照料动作：喂食、互动、清洁、休息、稳定激发
- 时间推进：每 5 秒一个成长刻，属性会自动衰减
- 状态事件：亢奋、胀气、粘污、饥饿躁动、共振态（影响成长倍率）
- 研究商店：可消耗研究点购买一次性增益道具

### 收集系统
- 育成仓：保存当前可培养个体
- 图鉴：记录首次发现物种 + 发现次数 + 合成路径
- 配方情报：消耗研究点逐条解锁提示
- 公司订单：实时 3 条订单，完成后获得研究点和材料奖励
- 订单连击：短时间连续完成订单会触发研究点加成

## 可视化与音效

- `src/render/petPainter.js` 使用 Canvas 动态绘制宠物
- 根据物种基因（形状/眼睛/角/尾巴/纹理）和阶段实时变化
- 正负状态会触发不同粒子特效
- `src/render/sound.js` 使用 WebAudio 提供创建、照料、进化、订单等音效
- 新增三套循环 BGM 主题（实验、培育、公司），会随移动端主面板切换

  main.js                  # 入口，事件绑定、时间循环、持久化提交

  game/
    state.js               # 存档模型、迁移、日志
    crafting.js            # 材料槽位、创建逻辑、重复共鸣处理
    economy.js             # 商店道具使用逻辑
    orders.js              # 订单生成、进度结算、连击奖励

  PROJECT_PROMPT.md        # AI 协作的项目提示词

## 本地运行

直接打开 `index.html` 即可运行（纯前端，无构建步骤）。

## 数据存档

- 使用 `localStorage`
- 存档 key：`oddity_company_v2`
- 支持基础迁移（旧字段兼容与默认值回填）
- 新字段包含：`speciesCount`、`duplicateAbsorbCount`、`mobilePane`、`soundOn`、订单连击字段

## 扩展建议

1. 在 `src/data/recipes.js` 新增物种与配方，不需改核心逻辑。
2. 在 `src/data/orders.js` 扩展订单模板，增强长期目标。
3. 在 `src/data/shop.js` 添加新道具，在 `src/game/economy.js` 接入效果。
4. 在 `src/game/simulation.js` 调整成长与状态事件参数，做平衡迭代。
5. 在 `src/render/petPainter.js` 增加新形态和更强的阶段特效。
